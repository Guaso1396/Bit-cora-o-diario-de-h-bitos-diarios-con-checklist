# Bitácora o diario de hábitos diarios con checklist
"Mi Rutina" es una aplicación móvil de seguimiento de hábitos diarios desarrollada con React Native + Expo. Permite al usuario registrar entre 3 y 5 hábitos simples (leer, hidratarse, meditar, hacer ejercicio, escribir), marcarlos como completados y visualizar su progreso en tiempo real.
